## B49 — Larger modals

**Goal:** Modals breathe. Edit/Create wider with taller textareas; History wider; Import wider.

**Files:**
- △ `ui/src/components/ui/dialog.tsx`:
  - Add `size?: 'sm' | 'md' | 'lg' | 'xl'` prop; default `'sm'` (preserves existing behavior for callers that don't specify)
  - Width mapping (approximate Tailwind classes):
