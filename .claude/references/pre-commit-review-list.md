# Pre-Commit Review List — DbConfig

> Fast, security-focused checks run before commit. Generated by setup-bootstrap from
> detected tools (.NET / EF Core / ASP.NET Core) + stack-agnostic always-includes.

- [EF Core] `AsNoTracking` on reads, async query methods, `CancellationToken` propagated; no name literals in `OnModelCreating`.
- [EF Core] Secret values (`IsSecret=true`) go through a real `IConfigEncryptor`, never `PassthroughConfigEncryptor`, outside tests.
- [ASP.NET Core] Admin UI/API endpoints have an authorization filter wired for non-local use (not the open two-arg `MapDbConfigUi` overload).
- [ASP.NET Core] No raw/interpolated SQL introduced in endpoint or store paths.
- No PII or secret values in logs.
- Tests for new public methods (Shouldly + xUnit v3; real providers via Testcontainers where relational behavior matters).
- No hardcoded secrets or connection strings.
